# 知了 · 门户通知同步（Chrome 扩展）

## 装一次

1. Chrome 地址栏输入 `chrome://extensions`，回车；
2. 右上角打开「**开发者模式**」；
3. 点「**加载已解压的扩展程序**」；
4. 选择这个文件夹：`zhiliao/app/extension`；
5. 列表里出现「知了 · 门户通知同步」就成功了。

## 用

1. 先确保本机知了在跑：`cd zhiliao/app && node server.mjs`；
2. 用 Chrome 打开校园门户 → 通知公告页（登录状态保持）；
3. 扩展会在页面加载后自动扫一次，之后每 20 秒扫一次；
4. 点扩展图标能看到「上次同步 / 新增几条」。

## 说明

- 只在 `portal.chd.edu.cn` 上运行，只读取页面上的标题、日期、部门；
- 只发给本机 `127.0.0.1:8787`，不经过任何外部服务器；
- 需要门户页面**开着**（可以切到别的标签，但别关）；
- 服务没启动时会提示「连不上本机知了」。

## 一键同步

扩展 ID 已固定为 `jpclkialpgklohaijlgnclcjgjakfjii`，知了网页上的「一键同步」按钮会直接调用它：

- 门户标签页开着 → 立刻扫一次；
- 没开 → 自动打开门户页，登录后自动同步。

**如果之前加载过旧版**：到 `chrome://extensions` 点该扩展的「移除」，再按上面步骤重新加载一次（因为 ID 变了）。
